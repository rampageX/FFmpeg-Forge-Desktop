# FFmpeg Forge Lite v2.3.2

Windows portable release based on the **user-tested** Scale/UX revision of v2.3.1.

## Changes

- **Independent Scale / AI Upscaling window** consolidates output resolution, conventional and GPU shader Scale, OptiScaler, SeedVR2, VisionNext/RazorNext, NVIDIA RTX VSR/TrueHDR/DLSS and Python/ONNX custom models without duplicating settings or changing the approved processing implementations.
- **Compatibility guide at the top of the Scale window** describes the real processing routes. Scale + OptiScaler and RTX VSR + TrueHDR remain combinable. Custom Python/ONNX can run as a separate preprocessing pass; conflicting whole-output routes switch automatically on checkbox selection.
- **Python / ONNX custom model section** expands only when `Use my AI model` is checked.
- **Settings mouse-wheel behavior** routes scrolling to the hovered outer settings panel without giving a control focus on hover; actively clicked controls and open dropdowns retain their native interactions.
- **Window geometry memory** for the main window, DVD/Blu-ray RIP, and Scale window: position, normal size and maximized state, saved in the existing settings file. Windows moved to unavailable displays are restored to a visible screen.
- Preserves previous Lite dark interface, responsive DVD RIP layout, shader / AI toolchain and small portable package.

## Distribution and verification

- One runtime attachment: `FFMpegForgeLite.zip`, plus GitHub autogenerated source archives. No separate source ZIP or checksums attached.
- EXE assembly, file and informational versions: **2.3.2** (assembly/file `2.3.2.0`).
- Portable package excludes `ffmpeg.exe`, `ffprobe.exe` and `ffplay.exe`. Supply your own FFmpeg build.
- Retains upstream helper executables and license notices, as previously.
- CI builds Windows EXE from the canonical `src/` tree and validates package manifest and SHA-256.
- UI regression tests include route compatibility, custom AI expand/collapse, all category modes, 16 toggle transitions, DVD RIP layouts (980×720 / 1180×860 / 1525×953), and three-window geometry persistence including an offscreen-monitor fallback.
- **Manual acceptance**: the user confirmed the Scale window, compatibility explanation, dark UX, and window placement behavior before authorizing this release.

**No previous Release, tag or upstream archive backup has been altered.**
